---

## 🍖 서비스 개요

**먹EATLIST**는 맛집을 단순히 검색하는 앱이 아닌,

**발견 → 방문 → 기록**의 과정을 즐길 수 있도록 설계된 **맛집 탐방 도장깨기 서비스**입니다!

기존 맛집 서비스가 정보 탐색에 집중했다면, **먹EATLIST**는 사용자가 직접 발로 뛰며 경험을 쌓는

**‘참여형 맛집 탐방’**에 초점을 뒀습니다!

---

## 🍖 기획 배경

![먹킷리스트 (2).png](%EB%A8%B9%ED%82%B7%EB%A6%AC%EC%8A%A4%ED%8A%B8_(2).png)

여행이나 음악처럼, 음식 역시 사람들에게 큰 즐거움을 주는 콘텐츠이지만 **맛집 탐방은 직접 방문하지 않으면 경험하기 어렵다는 한계가 있다**

흑백요리사와 먹방 유튜버 콘텐츠의 인기는 사람들이 맛집을 단순히 보는 데서 그치지 않고, **직접 찾아가 경험하고 기록하려는 수요가 충분히 존재함을 보여준다.** 이러한 수요를 바탕으로 방문 경험을 기록하고 도장처럼 쌓아가는 **먹EATLIST**를 기획하게 되었다.

## 🍖 이런 분께 추천해요

🍗 스크롤하다가 끌리는 맛집을 발견하는 걸 좋아하는 분

🍗 맛집 탐방을 **도장깨기처럼 즐기고 싶은 분**

🍗 “다음에 어디 가지?”를 고민하지 않고 **직관적으로 선택하고 싶은 분**

🍗 카테고리별로 **나만의 맛집 컬렉션을 완성하고 싶은 분**

🍗 먹는 것도 **취미이자 게임처럼** 즐기고 싶은 분

## 🍖스탬프 / 뱃지 기반 재미 요소

**먹EATLIST**는 **맛집 방문을 게임처럼 즐길 수 있도록** 스탬프와 뱃지 기능을 도입했습니다.

🍗 맛집 방문 완료 선택 시 **스탬프 적립**

🍗 카테고리별 방문 조건을 달성하면 **뱃지 획득**  

- **뱃지 종류 :** 브론즈/실버/골드/마스터
- **카테고리** : 흑백요리사/미슐랭/쯔양(유튜버)

🍗 누적된 스탬프를 통해 **나만의 스탬프 컬렉션 완성**

이를 통해 사용자는 
**“스탬프 적립, 뱃지를 획득을 하며 나만의 맛집 도장깨기 컬렉션을 완성하는 재미”** 를 경험할 수 있습니다.

**먹EATLIST**는 **맛집 방문을 게임처럼 즐길 수 있도록** 스탬프와 뱃지 기능을 도입했습니다.

🍗 맛집 방문 완료 선택 시 **스탬프 적립**

🍗 카테고리별 방문 조건을 달성하면 **뱃지 획득**  

- **뱃지 종류 :** 브론즈/실버/골드/마스터
- **카테고리** : 흑백요리사/미슐랭/쯔양(유튜버)

🍗 누적된 스탬프를 통해 **나만의 스탬프 컬렉션 완성**

이를 통해 사용자는 
**“스탬프 적립, 뱃지를 획득을 하며 나만의 맛집 도장깨기 컬렉션을 완성하는 재미”** 를 경험할 수 있습니다.
