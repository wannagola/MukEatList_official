# 🍖 먹EATLIST
### 나만의 맛집 도장깨기 서비스

> **세상의 맛집은 우리가 접수한다!**  
> 발견 → 방문 → 기록으로 완성하는 참여형 맛집 탐방 앱

---

## 📌 서비스 한눈에 보기

**먹EATLIST**는 맛집을 단순히 검색하는 앱이 아닌,  
사용자가 직접 방문하며 경험을 쌓고 기록하는  
**맛집 탐방 도장깨기 서비스**입니다.

기존 맛집 서비스가 정보 탐색에 집중했다면,  
먹EATLIST는 **사진에 끌려 선택하고, 방문으로 완성하는 경험**에 집중합니다.

---

## 🎯 기획 배경

여행이나 음악처럼 음식 역시 사람들에게 큰 즐거움을 주는 콘텐츠이지만,  
맛집 탐방은 직접 방문하지 않으면 경험하기 어렵다는 한계가 있습니다.

흑백요리사, 먹방 유튜버 콘텐츠의 인기는  
사람들이 맛집을 단순히 소비하는 데서 그치지 않고,  
**직접 찾아가 경험하고 기록하려는 수요가 충분히 존재함**을 보여줍니다.

이러한 흐름 속에서  
방문 경험을 기록하고 도장처럼 쌓아갈 수 있는 서비스의 필요성을 느끼게 되었고,  
그 결과 **먹EATLIST**를 기획하게 되었습니다.

---

## 🧩 핵심 기능

### 🔍 두 가지 탐색 방식

**① 가게 기준 탐색**  
카테고리별(흑백요리사 / 쯔양 / 미슐랭) 맛집 리스트를 통해  
목적이 명확한 탐색이 가능합니다.

**② 사진 기준 탐색**  
인스타그램 피드처럼 음식을 먼저 보고,  
자연스럽게 스크롤하다가 끌리는 가게를 선택할 수 있습니다.

> 사진 → 가게 정보로 이어지는 직관적인 탐색 흐름

---

## 🏷️ 스탬프 & 뱃지 시스템

먹EATLIST는 맛집 방문을 **게임처럼 즐길 수 있도록**  
스탬프와 뱃지 시스템을 도입했습니다.

- 방문 완료 시 스탬프 적립  
- 카테고리별 조건 달성 시 뱃지 획득  
- 브론즈 / 실버 / 골드 / 마스터 단계 구성  

> 스탬프를 모아  
> **나만의 맛집 도장깨기 컬렉션을 완성하는 재미**

---

## 👤 마이페이지

- 방문한 맛집 기록 관리  
- 카테고리별 스탬프 현황 확인  
- 획득한 뱃지 컬렉션 열람  

단순한 즐겨찾기가 아닌,  
**사용자의 취향과 탐방 히스토리를 시각적으로 남기는 공간**입니다.
