## 📌 서비스 개요

**먹EATLIST**는 맛집을 단순히 검색하는 앱이 아닌,  
**발견 → 방문 → 기록**의 과정을 즐길 수 있도록 설계된  
**맛집 탐방 도장깨기 서비스**입니다.

기존 맛집 서비스가 정보 탐색에 집중했다면,  
먹EATLIST는 사용자가 직접 방문하며 경험을 쌓는  
**‘참여형 맛집 탐방’**에 초점을 두었습니다.

---

## 🎯 기획 배경

![기획 배경](./assets/먹킷리스트_기획배경.png)

여행이나 음악처럼 음식 역시 사람들에게 큰 즐거움을 주는 콘텐츠이지만,  
**맛집 탐방은 직접 방문하지 않으면 경험하기 어렵다는 한계**가 존재합니다.

흑백요리사와 먹방 유튜버 콘텐츠의 인기는  
사람들이 맛집을 단순히 보는 데서 그치지 않고,  
**직접 찾아가 경험하고 기록하려는 수요가 충분히 존재함**을 보여줍니다.

이러한 흐름을 바탕으로,  
방문 경험을 기록하고 도장처럼 쌓아갈 수 있는 서비스의 필요성을 느끼게 되었고  
그 결과 **먹EATLIST**를 기획하게 되었습니다.

## 👍 이런 분께 추천해요

- 사진 보고 “어? 맛있겠다”가 먼저 나오는 분  
- 스크롤하다가 끌리는 맛집을 발견하는 걸 좋아하는 분  
- 다녀온 맛집을 **기록으로 남기고 싶은 분**  
- 맛집 탐방을 **도장깨기처럼 즐기고 싶은 분**  
- “다음에 어디 가지?”를 고민하지 않고 **직관적으로 선택하고 싶은 분**  
- 카테고리별로 **나만의 맛집 컬렉션을 완성하고 싶은 분**  
- 먹는 것도 **취미이자 게임처럼** 즐기고 싶은 분

## ⚙️ 기능 소개

### 🔍 두 가지 탐색 방식

#### ① 가게 기준 탐색
- 흑백요리사 / 쯔양 / 미슐랭 등 **카테고리별 맛집 리스트 제공**
- 목적이 명확한 사용자에게 적합한 탐색 방식

📽️ **카테고리별 맛집 확인**  
(시연 영상 첨부)

---

#### ② 사진 기준 탐색
- 인스타그램 돋보기처럼 **음식 사진을 먼저 확인**
- 사진 클릭 시 해당 가게의 상세 정보로 연결
- “사진 → 가게 정보”로 이어지는 **직관적인 탐색 경험**

📽️ **방문 확인 집계 / 식당 상세 페이지**  
(시연 영상 첨부)

---

## 🏷️ 스탬프 · 뱃지 시스템

먹EATLIST는 **맛집 방문을 게임처럼 즐길 수 있도록**  
스탬프와 뱃지 시스템을 도입했습니다.

- 맛집 방문 완료 시 **스탬프 적립**
- 카테고리별 방문 조건 달성 시 **뱃지 획득**
  - 등급: 브론즈 / 실버 / 골드 / 마스터
  - 카테고리: 흑백요리사 / 미슐랭 / 쯔양(유튜버)
- 누적된 스탬프를 통해 **나만의 스탬프 컬렉션 완성**

> 스탬프를 적립하고 뱃지를 획득하며  
> **나만의 맛집 도장깨기 컬렉션을 완성하는 재미**

📽️ **뱃지 작동 / 마이페이지 티어맵**  
(시연 영상 첨부)
